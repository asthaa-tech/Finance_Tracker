
# FinTrack 💰

A full-stack personal finance tracker built with Python, FastAPI, PostgreSQL, React, and TypeScript.

## Project Status

🚧 Under development

## Planned Features

- Income and expense tracking
- Budget management
- Financial dashboard
- Transaction categorization
- Monthly financial reports
- User authentication
- Responsive frontend

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL

### Frontend
- React
- TypeScript
- Vite

### DevOps
- Git
- Docker
- GitHub Actions
